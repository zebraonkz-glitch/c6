# c6

Браузерный калькулятор.

## Деплой на Vercel

### Через веб-интерфейс

1. Зайдите на [vercel.com](https://vercel.com) и войдите через GitHub.
2. Нажмите **Add New → Project** и выберите этот репозиторий.
3. Настройки сборки оставьте по умолчанию (статический сайт, без build-команды).
4. Нажмите **Deploy**.

После деплоя калькулятор будет доступен на корневом URL (`/`).

### Через CLI

```powershell
# Установка CLI (один раз)
pnpm add -g vercel

# Первый деплой из корня проекта
cd d:\work\c6
vercel

# Продакшен-деплой
vercel --prod
```
